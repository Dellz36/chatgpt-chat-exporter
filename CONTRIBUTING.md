# Contributing

Use Node.js 24 or newer. Install dependencies and run `npm test`. Use fictional fixtures only. Do not commit browser state, exports, screenshots of real chats, account identifiers, or personal configuration.

Keep `main` stable. Make focused changes on a branch such as `fix/search-preview`, run checks, review the diff, and open a pull request explaining behavior and validation. Merge only after review. Avoid force-pushing shared branches.

For endpoint changes, describe expected response structure using invented identifiers. Never share copied authentication headers or private payloads.
